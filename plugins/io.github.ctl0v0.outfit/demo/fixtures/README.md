# Dock Helper

A **fictional companion** for USB-C docks and MIDI controllers. Keep device status close at hand.

## Quick start

1. Connect your fictional dock.
2. Choose `Left`, `Center`, or `Right` in the plugin manager.

```sh
# Example only — no command is executed
omarchy plugin list --json
```

### Everyday controls

- **Status:** review connected accessories.
- *Quiet mode:* pause notifications while recording.
- Read the [configuration guide](docs/configuration.md) for more detail.

> All names and devices in this demo are fictional.
