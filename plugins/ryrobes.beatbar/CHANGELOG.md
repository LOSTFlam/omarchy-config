# Changelog

## 1.0.2 - 2026-09-02

- Show a one-time Omarchy OSD when the CAVA executable is unavailable instead
  of leaving the idle spectrum unexplained.
- Document the existing `setpriv` lifecycle helper supplied by Omarchy's base
  system.

## 1.0.1 - 2026-08-29

- Make the installation and privilege boundary machine-readable for marketplace
  validation.
- Remove the optional local installer; Beatbar never installs packages or asks
  for elevated access.

## 1.0.0 - 2026-08-28

- First community-ready release for Omarchy 4.x / Quattro.
- Add Garden, Mirror, and filled Aurora spectrum modes.
- Add bass-driven motion and an Aurora light sweep.
- Follow live Omarchy theme colors and default to the center bar section.
- Analyze the default PipeWire output mix with one shared CAVA service.
